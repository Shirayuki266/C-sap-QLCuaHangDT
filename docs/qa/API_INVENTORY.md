## Endpoint chẩn đoán và launcher

Ngoài 46 endpoint controller nghiệp vụ, GET /health/ready có trong mọi môi trường (public, không body; response application/environment/target/ready/code; HTTP200 hoặc503). Health kiểm tra schema bằng truy vấn read-only, không trả connection string hoặc credential; kiểm tra bởi PKG-START-LOCAL, PKG-DATABASE-UNAVAILABLE và các ca trong ADMIN_PACKAGING_REPORT.md.

Môi trường QA còn có GET /api/qa/identity (public, không nhận body; response environment/server/database; test QA-IDENTITY). Endpoint này không được map trong Development/Production. Nó chỉ xác nhận đích trước test ghi. Tổng khi QA chạy là46 route controller và2 route chẩn đoán minimal; các trạng thái inventory trên chỉ áp dụng44 controller.
