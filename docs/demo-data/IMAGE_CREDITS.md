# Image credits — current licensed demo catalog

150 local SVG files use49 distinct real source photographs for50 models. Each source generates one selected hardware/device crop and two labelled sub-crops of the same photo; these are not three independent camera angles. Some primary views are deliberately close-ups to exclude people, prices, unrelated devices and third-party advertising/app logos. Device-brand markings belong to the photographed model; no claim of manufacturer endorsement or exact color matching for every selectable variant is made.

These are educational demo photographs, not manufacturer packshots. The embedded raster bytes are unchanged downloads from the source URLs; clipping/scaling occurs in SVG. Cropping does not alter or invent hardware. The complete bitmap remains embedded for auditability; the displayed image is restricted to the recorded clip rectangle.

**CC BY-SA:** each cropped/derived image retains the same version of CC BY-SA as its source, including the SVG wrapper adaptation. Do not relicense these crops under the repository code license. Credit the source photographer, link the source and exact license, and state the crop/label changes when redistributing. CC BY crops retain their recorded CC BY version and required attribution; CC0 sources use the CC0 1.0 dedication. The code license does not override image licenses.

Crop coordinates below are pixels in the downloaded raster, origin top left: `x,y,width,height`, with downloaded dimensions for interpretation. Views2/3 are proper subsets of view1 (upper/lower detail). Native SVG clipping is limited to the scaled rectangle, so letterboxing cannot reveal excluded source regions. Full SHA256 and source-title metadata are in [real-products.json](../../tools/PhoneStore.DemoData/Catalog/real-products.json).
